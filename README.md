# Travel
A high-fidelity desktop admin dashboard designed in Figma for reviewing merchant websites submitted by Customer Support for final approval.
Tripora is a modern travel app UI/UX design created in Figma to help users explore destinations, discover hotels, plan trips, and manage bookings through a user-friendly interface.

Key Features
Destination discovery
Hotel search and details
Easy booking flow
Booking confirmation
Trip management

Tools Used
Figma
UI/UX Design
Wireframing and Prototyping
